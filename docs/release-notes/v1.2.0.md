## Agesen CamView 1.2.0 – first public release

Lightweight Windows viewer for up to 32 Hikvision IP cameras, with an on-screen
PTZ joystick. No browser or plugins needed.

### Highlights

- Up to 32 cameras or NVR channels, over pages of 4, 6, 9 or 16 cameras
- Click a camera to show it alone in full quality; Esc goes back
- PTZ control with joystick, zoom, speed and arrow keys, directly or through an NVR
- Finds Hikvision devices on the network and adds several at once
- Danish and English, switchable at runtime
- Customer name at the top of the window
- Passwords encrypted with Windows DPAPI
- Never retries a failed login, so cameras do not lock the PC out

### Install

1. Download `AgesenCamView-Setup-1.2.0.exe` below.
2. Run it. No administrator rights are needed.
3. If Windows SmartScreen shows "Windows protected your PC", choose
   **More info → Run anyway**. The installer is not code-signed.

Requires Windows 10 or 11, 64-bit. Everything else is included.
Silent install: `AgesenCamView-Setup-1.2.0.exe --silent --customer "Name" --lang en`.
See the README for all options.
